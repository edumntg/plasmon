Submit a job

The same job.yaml the command line uses. The server prepares the shards, so the dataset must be builtin://mnist or a directory the server can read. For a dataset on your own computer use plasmon job submit, which also seals the shards before they leave your machine when privacy.encrypt_shards is on.

Funding, who trains, and data exposure 
enrolment:
  mode: join            # auto: any idle machine that fits; join: trainers pick it from Open jobs
  approval: owner       # none, or owner: you approve each machine (you get a mail)
privacy:
  encrypt_shards: true  # shards sealed with a key only assigned machines receive
  sticky_shards: true   # a machine keeps the shards it already saw
  max_shards_per_machine: 4
budget:
  rounds: 20
  funding: 2000         # credits locked now; 100 per round on hold, released at the end
